# Инструкция по настройке Telegram Бота для TrainerSpace

Этот проект включает в себя встроенную логику для Telegram бота, который позволяет вашим клиентам записываться на тренировки. Бот автоматически синхронизируется с вашим расписанием в веб-панели.

## 1. Создание бота в Telegram

1. Найдите в Telegram бота [@BotFather](https://t.me/botfather).
2. Отправьте команду `/newbot`.
3. Введите название бота (например, `Мой Фитнес Бот`).
4. Введите username бота, оканчивающийся на `_bot` (например, `TrainerSpace_test_bot`).
5. **Сохраните полученный HTTP API Token.**

## 2. Настройка переменных окружения

Добавьте следующие ключи в ваш файл `.env.local`:

```env
# Токен вашего бота от BotFather
TELEGRAM_BOT_TOKEN=123456789:ABCDefGhIJKlmNoPQRstUVwXyZ

# Секретный ключ для защиты вашего вебхука (придумайте сами)
TELEGRAM_BOT_SECRET=super_secret_key_123

# Username вашего бота (без символа @)
NEXT_PUBLIC_TELEGRAM_BOT_USERNAME=TrainerSpace_test_bot

# Секретный ключ Supabase (Service Role) для работы бота в обход RLS
# Найти в Supabase: Settings -> API -> service_role (secret)
SUPABASE_SERVICE_ROLE_KEY=ваш_секретный_ключ
```

## 3. Установка Webhook

Чтобы Telegram знал, куда отправлять сообщения пользователей, нужно установить Webhook.

Выполните запрос в браузере или через `curl`, подставив свой токен и URL вашего развернутого приложения:

`https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook?url=https://<ВАШ_ДОМЕН>/api/bot?secret=<ВАШ_СЕКРЕТ>`

> **Примечание:** Для локальной разработки используйте [ngrok](https://ngrok.com/) или аналоги, чтобы пробросить локальный порт 3000 в интернет. URL будет выглядеть так: `https://abcd-123.ngrok-free.app/api/bot?secret=super_secret_key_123`.

## 4. Как пользоваться ботом

### Для тренера:
1. Зайдите в раздел **"Telegram-бот"** в вашей панели управления.
2. Скопируйте персональную ссылку (она выглядит как `https://t.me/ВашБот?start=ваш_id`).
3. Разместите эту ссылку в описании профиля Instagram, Telegram или отправьте клиенту лично.

### Для клиента:
1. Клиент переходит по вашей ссылке и нажимает **"Запустить" (Start)**.
2. Бот приветствует клиента и предлагает выбрать услугу.
3. После выбора услуги клиент выбирает дату и доступное время.
4. После подтверждения времени, в вашей панели управления в разделе **"Обзор"** или **"Заявки"** появится новое уведомление.
5. Вы можете подтвердить или отклонить заявку.

## 5. Возможные проблемы
- **Бот не отвечает (тишина):**
  1. Проверьте правильность `TELEGRAM_BOT_TOKEN` в `.env.local`.
  2. Убедитесь, что Webhook установлен с правильным `secret`. Если вы изменили `TELEGRAM_BOT_SECRET`, вам нужно **заново выполнить команду setWebhook**.
  3. Проверьте логи сервера Vercel (Logs) или терминала на наличие ошибок "Unauthorized" или "Bot token not configured".
- **Бот пишет "Тренер не найден":** Убедитесь, что вы переходите по полной ссылке с `?start=UUID`. Если вы просто написали боту `/start` без параметров, он не будет знать, к кому вас записать.
- **Нет доступных слотов:** Убедитесь, что у вас настроены рабочие часы в разделе "Расписание" и нет блокировок на выбранный день.
