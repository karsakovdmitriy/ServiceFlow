# TrainerSpace — Платформа для управления тренировками

**TrainerSpace** — это комплексное SaaS-решение для фитнес-тренеров, позволяющее автоматизировать процесс записи клиентов, управления расписанием и коммуникации через Telegram.

---

## 1. Архитектура

Проект построен на современном стеке технологий с упором на скорость работы, масштабируемость и безопасность.

*   **Frontend**: [Next.js](https://nextjs.org/) (App Router) на базе React 19.
*   **State Management**: Глобальный стор на React Context с поддержкой двух режимов:
    *   **Demo Mode**: Хранение данных в `localStorage` (для быстрого ознакомления без регистрации).
    *   **Cloud Mode**: Полноценная синхронизация с облачной базой данных.
*   **Backend/Database**: [Supabase](https://supabase.com/).
    *   **PostgreSQL**: Реляционная база данных.
    *   **Auth**: Управление пользователями (Email/Password).
    *   **RLS (Row Level Security)**: Разграничение доступа к данным на уровне строк (тренер видит только своих клиентов и свои записи).
*   **API**: Next.js API Routes для обработки вебхуков Telegram и системных уведомлений.
*   **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) — использование современных CSS-переменных и высокой производительности.

---

## 2. Функционал

### Для тренера (Web-интерфейс):
*   **Обзор (Dashboard)**: Краткая сводка по активным сессиям, новым заявкам, доходу и активности.
*   **Управление заявками**: Просмотр входящих запросов от клиентов, возможность подтверждения или отклонения.
*   **Расписание (Schedule)**:
    *   Настройка рабочих часов по дням недели.
    *   Блокировка конкретных временных интервалов (личные дела, отпуск).
    *   Визуальный обзор недели.
*   **Мои клиенты**: Единая база клиентов с историей посещений и контактными данными.
*   **Услуги (Services)**: Создание индивидуальных и групповых тренировок с указанием цены и длительности.
*   **Площадки (Venues)**: Управление локациями (залы, студии, уличные площадки) и привязка услуг к конкретным местам.
*   **Настройки**: Редактирование профиля тренера (имя, специализация, описание).

### Для клиента (Telegram Bot):
*   **Запись на тренировку**: Удобный пошаговый интерфейс выбора услуги, даты и времени.
*   **Уведомления**: Получение мгновенных подтверждений бронирования и напоминаний.
*   **Личный кабинет**: Просмотр своих предстоящих записей.

---

## 3. Интеграции

*   **Telegram Bot API**:
    *   Вебхуки для мгновенной обработки сообщений.
    *   Поддержка Deep-linking (`/start <trainer_id>`) для автоматической привязки клиента к тренеру.
    *   Inline-клавиатуры для навигации.
*   **Supabase**:
    *   Автоматическая инициализация профиля тренера и настроек расписания через триггеры БД при регистрации.
    *   Real-time уведомления (в планах).
*   **Система напоминаний**:
    *   Интеграция с Cron-задачами для автоматической рассылки напоминаний за 1 час до тренировки и сбора обратной связи через 1 час после завершения.

---

## 4. Дизайн

Дизайн системы ориентирован на чистоту, минимализм и удобство использования "на ходу".

*   **Адаптивность**: Интерфейс полностью оптимизирован под мобильные устройства:
    *   **Stats Grid**: На мобильных устройствах показатели отображаются сеткой 2x2.
    *   **Schedule**: "Обзор недели" на мобильных превращается в переключатель дней с детальным списком слотов для выбранного дня.
    *   **Clients**: Таблицы заменяются на карточный вид.
*   **Визуальный язык**: Использование мягких теней, закругленных углов (border-radius) и акцентного цвета (Indigo/Violet) для выделения важных действий.
*   **Иконографика**: Пакет `@tabler/icons-react` для единообразного и интуитивно понятного интерфейса.

## 5. Технические особенности

*   **Идемпотентность БД**: Все SQL-скрипты миграции (`docs/supabase_schema.sql`) поддерживают многократный запуск без ошибок (`CREATE TABLE IF NOT EXISTS`, `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`).
*   **Безопасность**:
    *   Валидация всех входящих данных (UUID, форматы дат).
    *   Секретные ключи для вебхуков Telegram (`TELEGRAM_BOT_SECRET`).
    *   Использование `Service Role Key` на сервере для обхода RLS только в доверенных операциях.
*   **Локализация**: Полная поддержка русского языка в интерфейсе и боте.
*   **Оптимизация**: Стандартизация форматов времени (HH:mm) на уровне стора для исключения ошибок сравнения.
*   **Групповые занятия**: Логика расчета слотов учитывает флаг `is_group`, позволяя нескольким клиентам записываться на одно и то же время, если услуга это предполагает.

## 6. User Stories

### Сценарий 1: Начало работы тренера
*Как тренер Алексей, я хочу быстро зарегистрироваться в системе, настроить свои рабочие часы (Пн-Пт с 9:00 до 20:00) и добавить услугу "Персональная тренировка" в клубе "Gold Gym", чтобы мои клиенты могли начать записываться.*

### Сценарий 2: Запись клиента через Telegram
*Как клиентка Анна, я перехожу по ссылке тренера в Telegram, нажимаю "Записаться", выбираю "Йога" на "Крыше мира", нахожу свободное время в среду на 10:00 и подтверждаю запись. Я тут же получаю уведомление, что моя заявка отправлена тренеру.*

### Сценарий 3: Подтверждение и автоматизация
*Как тренер Алексей, я вижу пуш-уведомление в Telegram и новую заявку на Dashboard. Я нажимаю "Подтвердить". Система автоматически отправляет Анне сообщение в Telegram с подтверждением и адресом площадки. За час до тренировки система сама напомнит ей о нашей встрече.*

### Сценарий 4: Управление нагрузкой
*Как тренер Алексей, я понимаю, что в следующую пятницу мне нужно уехать. Я захожу в раздел "Расписание", выбираю дату и нажимаю "Заблокировать весь день". Теперь клиенты через бота не увидят свободных слотов на этот день.*

## 7. Дальнейшее развитие (Roadmap)

1.  **Прием платежей**: Интеграция с платежными шлюзами для предоплаты тренировок.
2.  **Аналитика**: Расширенные графики доходов и посещаемости по месяцам.
3.  **Многопользовательские студии**: Поддержка аккаунтов для владельцев студий с несколькими тренерами.
4.  **Файловое хранилище**: Возможность прикреплять программы тренировок и планы питания в карточку клиента.
5.  **PWA**: Возможность установки сайта как мобильного приложения.
