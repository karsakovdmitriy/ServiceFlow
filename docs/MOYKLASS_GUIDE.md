# Инструкция по настройке интеграции с MoyKlass

Интеграция позволяет автоматически синхронизировать записи клиентов из вашего Telegram-бота TrainerSpace в CRM «Мой Класс».

## 1. Подготовка в «Мой Класс»

1.  Зайдите в ваш аккаунт «Мой Класс».
2.  Перейдите в **Настройки** -> **API и вебхуки**.
3.  Создайте новый API-ключ (назовите его, например, `TrainerSpace`).
4.  Скопируйте полученный ключ.

## 2. Настройка в TrainerSpace

1.  Откройте раздел **Настройки** (Профиль) в TrainerSpace.
2.  Прокрутите вниз до блока **Интеграция MoyKlass**.
3.  Переключите тумблер **«Активировать синхронизацию»**.
4.  Вставьте ваш API-ключ в соответствующее поле.
5.  Нажмите кнопку **«Проверить»**.
6.  После успешной проверки выберите **Филиал** из выпадающего списка, в который должны попадать записи.
7.  Нажмите **«Сохранить изменения»** внизу страницы.

## 3. Как это работает

*   **Регистрация клиентов**: Когда новый клиент запускает ваш бот, система ищет его в «Мой Класс» по телефону или Telegram-нику. Если клиент не найден — создается новый профиль в «Мой Класс».
*   **Запись на занятия**: При создании заявки через бот, TrainerSpace ищет подходящее занятие в расписании «Мой Класс» на выбранную дату и время. При нахождении соответствия — клиент автоматически записывается на это занятие в CRM.
*   **Логирование**: Все ошибки синхронизации отображаются в консоли сервера. В случае сбоя, запись в TrainerSpace все равно будет создана, чтобы вы не потеряли клиента.

## 4. Технические детали для разработчиков

Интеграция реализована в следующих файлах:
*   `src/lib/moyklass.ts` — API-клиент (v1/v2).
*   `src/app/api/bot/route.ts` — логика синхронизации при бронировании.
*   `src/lib/store.tsx` — метод тестирования соединения.
*   `docs/supabase_schema.sql` — новые поля в таблице `trainers`.

### Эндпоинты MoyKlass:
*   `POST /auth` — получение токена доступа.
*   `GET /users` — поиск клиентов.
*   `POST /users` — создание клиентов.
*   `GET /lessons` — получение расписания.
*   `POST /lessons/{id}/records` — запись на занятие.
