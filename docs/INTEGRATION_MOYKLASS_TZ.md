# Техническое задание: Интеграция TrainerSpace с CRM «Мой Класс»

## 1. Общие сведения
Данный документ описывает требования и архитектуру интеграции платформы **TrainerSpace** с системой автоматизации учебных центров **«Мой Класс»** через API v2.

### Цели интеграции:
*   Синхронизация базы клиентов между TrainerSpace и «Мой Класс».
*   Автоматическое создание записей на занятия в «Мой Класс» при бронировании через Telegram-бота TrainerSpace.
*   Единое расписание: отображение актуальных слотов с учетом занятости в обеих системах.
*   Учет посещаемости и статусов оплаты.

## 2. Архитектура и аутентификация
Интеграция строится на базе REST API «Мой Класс» v2.

### Параметры подключения:
*   **Базовый URL**: `https://api.moyklass.com/v1/` (или `v2/` для новых методов).
*   **Аутентификация**:
    1.  Получение временного токена доступа (`accessToken`) через API-ключ компании.
    2.  Передача токена в заголовке `x-access-token` для всех последующих запросов.

### Ключевые эндпоинты для настройки:
*   `POST /v2/auth` — Авторизация и получение токена.
*   `GET /v2/company` — Получение данных о компании и филиалах.

## 3. Маппинг сущностей

Для корректной работы интеграции необходимо сопоставить объекты TrainerSpace с сущностями «Мой Класс».

| TrainerSpace (DB) | Мой Класс (API) | Описание |
| :--- | :--- | :--- |
| `trainers` | `managers` / `teachers` | Профиль тренера или администратора филиала. |
| `clients` | `users` | Карточка ученика/клиента (Email, Phone, Telegram ID). |
| `services` | `courses` / `programs` | Программы обучения или типы тренировок. |
| `venues` | `filials` / `rooms` | Локации и залы, где проводятся занятия. |
| `sessions` | `lessons` / `records` | Конкретное занятие в расписании и запись клиента на него. |

## 4. Сценарии синхронизации

### 4.1. Создание/обновление клиента
При регистрации нового клиента в TrainerSpace (через Telegram-бота) или обновлении его данных:
1.  Выполняется поиск клиента в «Мой Класс» по Email или Телефону (`GET /v2/users`).
2.  Если клиент найден — обновляются его данные и сохраняется `externalId` (ID из «Мой Класс»).
3.  Если клиент не найден — создается новый профиль (`POST /v2/users`).

### 4.2. Бронирование тренировки (Запись на занятие)
Когда клиент подтверждает запись в Telegram-боте TrainerSpace:
1.  **Поиск занятия**: TrainerSpace ищет соответствующее занятие в расписании «Мой Класс» (`GET /v2/lessons`).
2.  **Создание записи**: Выполняется запрос на добавление клиента в список участников занятия (`POST /v2/lessons/{lessonId}/records`).
3.  **Обработка результата**: При успешной записи статус в TrainerSpace меняется на `confirmed`. Если в «Мой Класс» нет мест или занятие отменено — клиенту отправляется уведомление об ошибке.

### 4.3. Синхронизация расписания (Доступные слоты)
Для предотвращения овербукинга:
1.  TrainerSpace регулярно (или при запросе слотов) запрашивает список занятий из «Мой Класс» (`GET /v2/lessons`).
2.  Занятые интервалы в «Мой Класс» автоматически блокируют соответствующие слоты в TrainerSpace.

## 5. Вебхуки (Обратная связь)

Для получения оперативной информации из «Мой Класс» необходимо настроить Webhook-листенер в TrainerSpace.

### Отслеживаемые события:
*   `lesson_changed` / `lesson_deleted` — обновление локального расписания.
*   `record_changed` — изменение статуса записи (например, клиент отменил запись через ЛК «Мой Класс»).
*   `user_changed` — обновление данных клиента.

### Требования к реализации:
*   Эндпоинт: `POST /api/webhooks/moyklass`.
*   Проверка подписи запроса (если поддерживается API) для обеспечения безопасности.
*   Идемпотентность обработки: проверка ID события перед внесением изменений в БД.

## 6. Логирование и обработка ошибок

1.  **Централизованное логирование**: Все API-запросы должны сохраняться в таблицу `integration_logs` (ID тренера, Метод API, Тело запроса, Ответ, Статус).
2.  **Система очередей**: При сбое API (5xx) запрос должен быть поставлен в очередь на повтор (Retry Policy: 3 попытки с экспоненциальной задержкой).
3.  **Уведомления администратора**: При критических ошибках синхронизации тренер получает уведомление в Telegram.
