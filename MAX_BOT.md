# Инструкция по настройке MAX Messenger Бота для TrainerSpace

Этот проект поддерживает интеграцию с российским мессенджером MAX, позволяя клиентам записываться на тренировки через привычный интерфейс.

## 1. Регистрация в MAX для бизнеса

1. Перейдите на портал [MAX для разработчиков](https://dev.max.ru/).
2. Авторизуйтесь под своей учетной записью или зарегистрируйте организацию (доступно для юрлиц РФ).
3. В разделе управления ботами создайте нового бота.
4. **Сохраните полученный API Токен.**

## 2. Настройка переменных окружения

Добавьте следующие ключи в ваш файл `.env.local`:

```env
# Токен вашего бота MAX
MAX_BOT_TOKEN=ваш_токен_из_панели_разработчика

# Секретный ключ для защиты вашего вебхука
MAX_BOT_SECRET=ваш_придуманный_секрет

# Username вашего бота в MAX (без символа @)
NEXT_PUBLIC_MAX_BOT_USERNAME=TrainerSpace_bot
```

## 3. Установка Webhook

Для того чтобы сообщения из MAX попадали в ваше приложение, нужно настроить Webhook в панели управления MAX или через API:

`POST https://platform-api.max.ru/subscriptions`
Header `Authorization: <ВАШ_ТОКЕН>`
Body:
```json
{
  "url": "https://<ВАШ_ДОМЕН>/api/max-bot?secret=<ВАШ_СЕКРЕТ>",
  "event_types": ["message_created", "message_callback"]
}
```

## 4. Как пользоваться ботом

### Для тренера:
1. В веб-панели перейдите в раздел **"Telegram-бот"** (теперь там отображаются ссылки для обоих мессенджеров).
2. Скопируйте персональную ссылку для MAX (она выглядит как `https://max.ru/bot/ВашБот?start=ваш_id`).
3. Разместите эту ссылку в ваших социальных сетях или отправьте клиенту.

### Для клиента:
1. Клиент переходит по ссылке и попадает в чат с ботом в MAX.
2. После нажатия **"Начать"** (или отправки команды `/start`), бот предложит выбрать услугу, дату и время.
3. Все действия клиента мгновенно отображаются в вашей панели управления.

## 5. Особенности работы
- Интеграция с MAX полностью дублирует функционал Telegram-бота.
- Уведомления о новых заявках приходят тренеру в оба мессенджера, если они привязаны.
- Для подтверждения/отклонения заявок, пришедших из MAX, рекомендуется использовать веб-интерфейс или Telegram (в текущей версии).

## 6. Возможные проблемы
- **Бот не отвечает:** Проверьте `MAX_BOT_TOKEN` и статус подписки на вебхук в панели MAX.
- **Ошибка авторизации:** Убедитесь, что токен передается в заголовке `Authorization`.
