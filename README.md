# TrainerSpace — Прототип системы для фитнес-тренеров

Этот проект представляет собой функциональный прототип системы управления тренировками, клиентами и расписанием.

## Технологии
- **Next.js 15 (App Router)** — Frontend и API
- **Supabase** — База данных и Авторизация
- **Tailwind CSS v4** — Стилизация
- **Tabler Icons** — Иконки

## Как запустить локально

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

## Деплой на Vercel
Самый быстрый способ развернуть этот проект — использовать Vercel. [Инструкция по деплою](VERCEL_DEPLOY.md).

## Подключение к Supabase

По умолчанию проект запускается в **Демо-режиме** (данные сохраняются в LocalStorage вашего браузера). Чтобы включить облачную синхронизацию:

1. Создайте проект на [supabase.com](https://supabase.com).
2. Создайте файл `.env.local` в корне проекта и добавьте ваши ключи:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=ваш_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_ключ
   ```
3. Выполните SQL-запрос из файла `docs/supabase_schema.sql` в разделе **SQL Editor** вашей панели Supabase. Это создаст необходимые таблицы, триггеры и политики безопасности (RLS).

## Ключевые функции
- **Авторизация**: Вход и регистрация через email.
- **Расписание**: Настройка рабочих часов и блокировка времени.
- **Услуги**: Управление списком услуг и ценами.
- **Заявки**: Прием и обработка новых запросов на тренировки.
- **Клиенты**: База активных клиентов с фильтрацией.
- **Telegram Бот**: Полноценная запись для клиентов через бота. [Инструкция по настройке бота](TELEGRAM_BOT.md).

## Разработка
- `src/lib/store.ts` — Основная логика управления состоянием.
- `src/app/` — Страницы приложения.
- `src/components/` — Общие компоненты (Sidebar, Topbar, Modals).
- `docs/supabase_schema.sql` — Структура базы данных.
